# 📐 Projeto Página Exata (Hub Educacional)

![Status do Projeto](https://img.shields.io/badge/Status-Em_Desenvolvimento-blue)
![Tecnologias](https://img.shields.io/badge/Tech-Vue.js%20|%20HTML5%20|%20CSS3-green)

O **Página Exata** é um ecossistema digital concebido para modernizar o ensino da Matemática e Geometria. Este projeto une a minha experiência de mais de uma década como Professor na rede pública da Bahia (Camaçari) com as competências técnicas que estou a desenvolver no curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

## 🚀 Sobre o Projeto

Este repositório funciona como um **Hub**, integrando:
1.  **Nova Plataforma Reativa:** Desenvolvida com **Vue.js**, incluindo calculadoras de áreas em tempo real e geradores de desafios matemáticos.
2.  **Arquivo Histórico (Legado):** Preservação do conteúdo pedagógico anterior, integrado via subdiretórios.
3.  **Laboratório de Geometria:** Resoluções interativas de exercícios utilizando mesa digitalizadora (XP-Pen), focadas em Geometria Plana e Espacial.

## 🛠️ Tecnologias Utilizadas

-   **Frontend:** HTML5, CSS3 (com suporte a Dark Mode) e JavaScript (ES6+).
-   **Framework:** [Vue.js 3](https://vuejs.org/) (via CDN para máxima performance e simplicidade).
-   **Ferramentas de Desenvolvimento:** Sublime Text no ambiente **Linux** (Zorin OS / ChromeOS Flex).
-   **Versionamento e Deploy:** Git, GitHub e GitHub Pages.

## 📂 Estrutura do Repositório

* `/css`: Folhas de estilo com variáveis para personalização de temas.
* `/js`: Lógica reativa, manipulação do DOM e persistência com `localStorage`.
* `/img`: Ativos visuais e resoluções de exercícios de geometria.
* `/legado`: Versão anterior do site, mantendo a continuidade do acesso dos alunos.
