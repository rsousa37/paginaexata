Euklid

Graphmatematica
Tamanho: 217Kb
Formato: zip

Com este programa é possível criar vários gráficos de funções de uma só vez, traçar a tangente a um ponto do gráfico, traçar a função derivada etc. A cópia é totalmente funcional, podendo copiar o trabalho em vários formatos, em cores ou monocromático. Se você ensina ou estuda no ensino médio, este é um ótimo programa para traçar os gráficos das funções elementares, pois é prático e consome pouco espaço em disco e memória.
