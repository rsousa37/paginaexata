Princípios Básicos

O funcionamento de um computador é controlado por um programa. Um programa é uma seqüência de códigos armazenados na memória do computador, que contém todos os procedimentos da tarefa a ser realizada. Um programa é escrito em uma linguagem de programação.

Operações Básicas Realizadas Por Um Computador:

Um computador funciona basicamente efetuando três operações:

  • Entrada de Dados;

  • Processamento de Dados;

  • Saída de Dados.

Como um computador funciona a partir de um programa, teremos por conseqüência que um programa cumprirá as etapas acima. Estas etapas serão sempre cumpridas.

Tenha sempre na memória a ordem destas etapas, pois este é o principal ponto de partida para o desenvolvimento da lógica para um programa.

As Entradas de Dados

Entrar dados é a operação de passar para memória do computador as informações previamente preparadas pelo ser humano.

Alguns dispositivos utilizados para a entrada de dados são: teclados, leitora de cartões magnéticos(muito comuns em bancos), leitoras de discos magnéticos, leitoras óticas(muito comuns nos balcões de supermercados).

Os Processamentos dos Dados

A etapa do processamento dos dados envolve tanto a manipulação das informações fornecidas pelo usuário, como as operações internas do funcionamento do programa.

Esta etapa efetua todas as operações aritméticas e lógicas, que são as bases de funcionamento de qualquer computador.

As Saídas dos Dados

Sair dados é fornecer os resultados obtidos após a manipulação(processamento) das informações fornecidas(entradas).

Alguns dispositivos de saída de dados são: Monitor de Vídeo e Impressoras.

Obs.: Alguns dispositivos servem tanto para entrada como saída de dados. Por exemplo: Disco Magnético (Dispositivo de Entrada quando é lido e Dispositivo de Saída quando é gravado nele).

 

Tendo os princípios acima em mente, podemos seguir para a construção da lógica da programação. A construção da Lógica ANTECEDE a codificação.
