Linguagem de Programação: Conjunto de códigos utilizados para "instruir" o computador para realizar uma determinada tarefa.

As linguagens de programação dividem-se em duas categorias:

  • Linguagem de Baixo Nível: Utiliza códigos binários(linguagem de máquina) ou Códigos Mnemônicos(linguagem assembler). Esta característica torna as linguagens de baixo nível de difícil compreensão.
  • Linguagem de Alto Nível: Utiliza como códigos palavras da linguagem humana.
    A linguagem FORTRAN foi a primeira linguagem de alto nível, criada em 1959. Seguiram-se então a liguagem BASIC, PASCAL e COBOL; ao longo do tempo criaram-se muitas outras com diferentes objetivos.

Exemplos

Um programa em linguagem ASSEMBLER:

0C1B:0100 mov ax,0002
0C1B:0103 mov bx,0004
0C1B:0106 add ax,bx
0C1B:0108 int 20
0C1B:010A

Um programa em linguagem FORTRAN:

* Calculo da distancia entre dois pontos no plano*
****************************************************
******* AUTOR: ROBSON SILVA DE SOUSA *********
****************************************************
REAL DIST,X1,Y1,X2,Y2
DIST=0
X1=0
Y1=0
X2=0
Y2=0
WRITE(*,*)'DIGITE A ABCISSA DE P1'
READ(*,*)X1
WRITE(*,*)'DIGITE A ORDENADA DE P1'
READ(*,*)Y1
WRITE(*,*)'DIGITE A ABCISSA DE P2'
READ(*,*)X2
WRITE(*,*)'DIGITE A ORDENADA DE P2'
READ(*,*)Y2
DIST=SQRT((X2-X1)**2+(Y2-Y1)**2)
WRITE(*,*)'A DISTANCIA ENTRE OS DOIS PONTOS E ',DIST
END
